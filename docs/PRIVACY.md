# 隐私

- 不包含分析、广告、遥测、云上传或远程代码加载。
- SIM 标识只用于本机身份验证与恢复绑定，保存在应用私有状态中，不作为公开日志或报告内容。
- 原值、历史和恢复状态保留在本机；失败、升级或后端切换不会主动删除原值。常规卸载可能删除应用私有数据。
- 无线 ADB 密钥保留在应用私有存储；配对码不进入日志或偏好设置。认证接口不提供任意命令执行器。
- 网络探测、指定服务的公网 IP 查询与用户选择的导出会接触相应服务或目标；这些操作不会自动运行。
- 分享报告使用固定字段白名单，排除订阅标识、配对秘密、IP 地址、小区标识和位置细节。导出前仍应审阅。

应用运行时处理 SIM 身份是恢复保护的一部分，不代表项目仓库包含任何真实 SIM 记录。测试中的标识是明确构造的虚构样本。

向项目提交反馈时，只附脱敏后的诊断。不要提交设备序列号、电话号码、ICCID/IMSI、私钥、访问令牌、个人网络地址、完整系统日志或签名密钥。
