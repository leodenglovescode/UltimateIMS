# 架构

- core：配置白名单、SIM 身份、草稿绑定、恢复日志、批量写入策略、结果核验及纯逻辑测试。
- app：Material 3 界面、实时观测、后台工作区、每应用语言与可定制外观。
- backend：官方 Shizuku 或独立私有传输；认证 Binder 窄接口、应用 UID broker、短时权限委托和串行调用。

同卡 CarrierConfig 以一次白名单 bundle 提交，有限等待整个集合匹配，随后最终复核。原值先持久保存；超时、身份改变、权限丢失或不匹配保留恢复需要状态。不以 API 返回、保存历史或显示图标冒充验证结果。

订阅偏好、设备全局设置和 APN 使用独立作用域，批量提交不是跨 SIM 或基带的原子事务。恢复使用各卡原值，不猜测未知/未设置值。

自动连接只在前台复用已选授权；后台不启动 root 或配对。存活失联会话及未知结果留待明确恢复。自动连接与用户另行开启的配置重应用分开。

业务状态通过稳定枚举映射到翻译资源；原始框架键、数值、协议和英文运行日志保留原文。语言选择使用 Android LocaleManager；自动模式按系统首选语言解析中文变体或英语回退。

外观设置独立保存，默认跟随系统。照片经系统选择器授权后在工作线程解码，最长边限制为 1600 像素，重编码后用 AtomicFile 保存于 noBackupFilesDir；不记录原 URI 或元数据。导入状态放入 ViewModel，避免旋转丢失结果。外观重置不访问后端、SIM 原值或恢复日志。

玻璃风格把清晰壁纸与共享模糊 RenderNode 分开；GlassSurface 根据窗口坐标采样模糊背景，再绘制可调透射色与高光，前景控件单独绘制。滚动时只使玻璃表面失效以重新对齐，壁纸与模糊节点共享，不逐帧截屏或递归捕获自身。外观滑块仅更新渲染参数与偏好，不触发后端调用。
