# 功能与验证边界

“已接入”表示真实 UI/API 路径存在，不等于所有固件已通过设备测试。

| 能力 | 作用域与实现 | 验证边界 |
|---|---|---|
| VoLTE / VoWiFi / VoNR / VT / Cross-SIM / UT | 每卡可用性、配套设置和独立用户偏好 | provisioning、注册与通话分别检查；不能由开关推断 |
| NSA / SA 与显示 | NR 模式、5G+ 图标、门槛、LTE/4G 标注 | 显示不增加基带能力，不保证吞吐或 VoNR |
| 持久化 VoLTE | 订阅 opt-in/高级通话偏好、原值备份与恢复 | 与 CarrierConfig 重应用分开；重启行为需固件验收 |
| SIM 地区兼容 | 明确确认的固定三位数地区覆盖 | 不附带改 MCC/MNC，不保证特定应用可用 |
| 连接诊断 | 独立 USER/POWER/CARRIER 掩码、注册与网络观测 | 读不到保持未知；不关闭省电策略 |
| 门户 / APN / 公网 IP | 设备级门户、审阅过的 APN、用户指定查询 | 各自确认/恢复，不自动联网探测或上传 |
| 配置与恢复 | 单卡/明确全卡、草稿、历史、整组核验和中断恢复 | 所有原值先保存；失败不丢备份、不盲目重试 |
| 后端 | 官方 Shizuku、私有无线 ADB、已有 root | 认证窄接口；真实无线配对仍需逐设备验证 |
| 界面 | Material 3、跟随系统外观、中英文、可访问性语义 | 文本放大、TalkBack、导航模式等需实机回归 |

主机测试覆盖配置映射、SIM 身份、原值保存、恢复、权限/认证边界、异步回读、未知结果、自动重连授权条件及本地化解析。主机验证不能代替运营商、完整通话或重启验收。
