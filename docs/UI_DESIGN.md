# Material UI 与导航设计

当前增量：2026-10-09，0.4.0-dev。采用官方 Material 3 控件；以平面列表、分组标题与分隔线取代选项卡片。

## 页面分工

- **IMS 与无线**：所选 SIM、默认数据卡/地区/数据网络类型、IMS 注册与传输、VoNR 能力和可用性、真实数据注册证据；同页提供 VoLTE、VoWiFi、VoNR/Vo5G、视频、跨卡、UT、LTE、5G NSA/SA 开关。Vo5G 是 VoNR 的另一个称呼，不添加虚假的第二种能力。
- **配置**：明确选择后端、官方 Shizuku 或私有 ADB/root 的连接动作、可选重应用，以及 Wi-Fi calling 偏好、用户设置、阈值、图标、运营商/高级配置。搜索直接过滤平面列表。
- **网络**：设备级连接检查端点。
- **工具**：持久化 VoLTE、原值恢复、维护、历史与日志。
- 应用设置只包含系统外观、可选壁纸颜色、语言、隐私和应用信息。完整连接诊断从 IMS 页面进入；不再单独占据底部目的地。

紧凑窗口使用四个底部目的地；大字号/宽窗口使用导航抽屉。正文、标题、输入均使用 Material 字体等级和语义色，宽屏限制可读行长。文字允许换行，按钮/开关保持至少 56dp。

## 开关与当前状态

- 布尔 CarrierConfig 与 0/1 用户偏好以 MaterialSwitch 编辑草稿。真实 -1 默认值不伪装成关闭。
- 不可读、默认或未设置值显示明确文字，禁用无法确定状态的开关；可通过“明确选择启用或禁用”准备显式草稿。无法核验原值时仍由恢复引擎拒绝实际写入。
- NSA=1、SA=2 的数组字段分为两个开关；修改一项保留另一项，明确关闭两项生成空数组。未知枚举保持未知而不猜测。
- 注册观测带读取时间，并与配置开关分开。配置启用不证明 modem 注册、5G 连接或 VoNR 通话。
- 开关不立即写设备。统一审阅显示目标 SIM 数量和每项当前值 → 草稿值；应用仍需要原有身份验证、原值备份、回读与额外地区确认。

## 系统外观

启动和系统变化时始终使用 AppCompat 的 FOLLOW_SYSTEM；旧版手动浅/深色偏好不再控制外观。Material You 壁纸配色默认启用，可在应用设置关闭。主题重建保留草稿、搜索、全卡范围与 SIM 选择；不会自动启动特权服务或应用草稿。

## 后端路径

Shizuku 预检和授权在绑定私有 broker 前完成；缺少服务、拒绝授权或服务在预检后死亡时给出可重试状态。授权回调核对请求编号和启动 epoch，停止后不接受旧回调。重复绑定/认证受保护，root 固定命令绑定当前 epoch。

认证与普通操作共享串行 RPC 队列，认证等待最多 20 秒。超时保留真实 Future、不取消远端，不报告成功；后台操作收敛后刷新 UI，使明确停止/恢复重新可用。启动的认证快照只交接一次给工作台，避免第二次完整 SNAPSHOT；不从保存历史推断当前值。无消费者的旧 IMS UI 观察回调已移除，注册数据由统一框架读取路径提供。

上述改进经过编译和核心映射检查；真实 Shizuku/Binder/instrumentation 路径未测试，不宣称速度或设备成功。

## 0.5.3-dev 紧凑列表

应用显示名称为 Ultimate IMS。所有布尔选项使用一行 MaterialSwitch 胶囊开关，正常 56dp 触控高度；不再为每项显示当前值段落、独立卡片或“选择启用/停用”按钮。未知字段明确标注且禁用；已知 -1 用户默认值可明确选择新草稿值。未选择的默认值不写成关闭。值域不是布尔的偏好、阈值、端点仍用可编辑行/对话框，避免用开关伪装数字或枚举。

首页仅显示 IMS、连接类型、实际移动网络三项摘要；能力、注册技术、默认数据卡、区域和原始网络信息移到连接详情。后端选择为下拉行、连接与自动恢复为开关；单独显示实时读取可用性，错误详情按需打开。详细限制保留在诊断、工具和确认窗口。

旧草稿缺少可核验的绑定或目标 SIM 改变时，Review changes 先展示目标 SIM 并要求明确确认；第一次确认不执行配置写入。原值与恢复日志不随 UI 精简删除。系统主题、语言机制保持不变。

0.5.0 紧凑暗色界面在设备截图中检查，实际 switch 行高 168px/56dp，未点开网络配置开关。最终 0.5.3 只安装，视觉变化及完整中英文/大字体/TalkBack 尚未真机验收。

## 0.6.0-dev 复合显示开关

IMS 与无线页的“5G 显示”分组提供两行 Material 胶囊开关：5G+/5GA 显示预设、大陆风格5G信号格。长按查看具体参数与限制；不在每个选项下增加说明段落。开关状态从当前实时字段与显式草稿计算，不从历史推断；任一所需字段不可读则未知且禁用。

开启只准备该预设的字段。关闭尚未应用的预设恢复该组之前的草稿，不删除其他配置；关闭已应用的预设读取并准备已保存原值。缺少原值或载入的原值本身也匹配该预设时明确拒绝，不假造“关闭”。应用全部 SIM 时，各卡分别取自己的原值并在确认窗口列出，不能用第一张卡原值覆盖第二张卡。最终计划绑定确认时的 SIM 身份，并输出逐卡结果。

预设前草稿及待恢复标记随活动状态保存，导入/载入预设/放弃整个草稿时清理相应标记；不删除私有原值日志。未进行本版真机界面或显示效果验收。
