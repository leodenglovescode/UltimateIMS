# Material UI 与可访问性设计

## 页面与信息层级

- 紧凑窗口使用五个 Material 导航栏目的地：状态、通话、诊断、网络、工具。应用设置通过工具栏进入；刷新是独立操作。
- 屏宽达到 600dp 或字体缩放达到 130% 时改用 Material 导航抽屉，显示六个完整页面名称，允许多行，避免压缩五个标签。宽屏内容最大可读宽度 840dp；窄屏留 16dp 外边距。
- 状态卡保留读取时间、不确定状态与逐卡结果；未就绪显示连接设置入口。未知不等同于关闭；历史不替代实时读值。
- 通话页先选 SIM，再准备草稿；配置分为通话能力、Wi-Fi 通话、用户偏好、5G、网络标签/图标、运营商/高级六组。可折叠和搜索；每行同时展示实时值与草稿值，整行打开编辑。
- 应用前仍需要明确审阅目标、范围和差异。所有 SIM 是显式勾选，刷新/外观重建保留勾选；改变外观不执行草稿。
- 网络端点、恢复、持久化 VoLTE、维护、日志、APN 与主动 IP 查询采用独立卡片，保留其原有授权与确认。

## 外观与可读性

采用官方 Material Components 1.14.0 与 AppCompat 1.8.0，Material 3 DayNight 主题。选项为跟随系统、浅色、深色；偏好保存在独立私有外观文件。可选择 Material You 壁纸配色，默认关闭。系统栏图标随当前主题切换。

操作按钮最小 56dp，设置行最小 72dp；SIM 下拉、输入与勾选保持至少 56dp。保留文本标签，不用颜色作为唯一状态表达。分组标记可访问性标题与展开状态；编辑行读出字段、实时/草稿值及操作。正文可以选择复制；可操作行采用统一朗读内容，避免重复子节点。

输入采用 Material outlined TextInputLayout 和持续标签。SIM 下拉允许多行，菜单项使用项目自己的可换行布局。配置编辑错误留在对话框并显示字段错误，不关闭后丢失输入。表单可滚动，键盘与系统/刘海区域都有 inset 处理。正常刷新保留页面滚动与搜索位置，主题重建保留草稿、搜索、分组与所选 SIM。

维护 reset 采用 error 语义色并保留文字/确认；正常主要应用操作用 filled 按钮，其余辅助操作用 outlined 按钮。危险动作的调用与恢复语义没有因视觉改造改变。

## 验证边界与依据

本次仅执行主机编译、lint、翻译键/占位符检查、静态色对检查及 APK 签名/对齐检查。未重新运行核心/配对测试，未继续 ADB 安装或测试新版 UI。仍需后续明确授权后验收：系统浅/深切换、200% 字体、中文/英文长文本、TalkBack/键盘焦点、横屏/窗口缩放、键盘表单、主题重建后的草稿、后台读值刷新与抽屉返回键。

官方依据：[Material 色彩角色](https://m3.material.io/styles/color/the-color-system)、[Material 顶部应用栏](https://m3.material.io/components/app-bars/)、[Android 深色主题](https://developer.android.com/develop/ui/views/theming/darktheme)、[Android 可访问性](https://developer.android.com/guide/topics/ui/accessibility/apps)。这些是实现依据，不能代替实际用户体验验收。
