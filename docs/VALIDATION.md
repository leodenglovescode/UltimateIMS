# 验证

开发构建已通过 Gradle 单元测试、Android lint 和 APK 构建。现有核心测试为 179 项；lint 仍有隐藏 API 等相关警告，不宣称零警告。

测试覆盖：配置映射、虚构 SIM 身份、持久原值、选择性恢复、升级追加字段、未知结果、权限丢失、异步整组回读、语言选择和自动连接策略。测试中的标识与密钥均为构造样本，不是真实账户或 SIM 记录。

有限设备检查包括前台 Shizuku 自动连接/认证、部分实时 NR/IMS 读取与窗口布局观察。这不是所有 Android 13+、所有后端、所有运营商或全部功能的验收。

仍需独立验证：完整无线 ADB 配对、重启持久性、实际通话与 VoNR 媒体、SIM 更换恢复、权限撤销和未知超时的设备故障注入，以及大字号/TalkBack/三键导航/键盘组合。

仓库不提供个人设备配置快照、设备编号、完整运行日志或本机开发路径。对外报告应只使用脱敏数据，并区分主机测试、只读观测与实际通信行为。
