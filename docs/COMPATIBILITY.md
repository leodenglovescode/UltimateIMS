# 兼容性与限制

最低 Android 13（API 33），优先 Tensor Pixel。不能按品牌或系统版本推断某项功能已验证；运营商开通、基带能力和厂商固件仍决定实际效果。

## 后端

- 官方 Shizuku：必须选择并授权。应用在前台可自动连接已选、已授权且正在运行的服务。
- 私有无线 ADB：用户明确配对和连接，本机受限连接；真实配对仍需设备验证。
- 已有 root：明确选择并启动，不自动获取 root。

不静默切换后端；未知结果或在途操作阻止盲目重试。隐藏 API 逐签名检查，缺失或不可读保持未知。

## 通信与显示

配置可用性、用户偏好、实际注册、通话技术和图标是不同证据。5G+ 显示设置不会增加调制解调器能力或保证网速。省电模式可能排除 NR；应用只说明，不强行更改电源策略。

持久化 VoLTE 独立保存订阅 VoIMS opt-in 和高级通话偏好，不等于重放 CarrierConfig。原值必须可读且可恢复；重启后效果需要固件验证。修改配置不能替代运营商 provisioning。

SIM 地区兼容选项需明确确认，只针对选中 SIM 的地区覆盖，不附带修改 MCC/MNC。其他读取 SIM 地区的应用也可能受到影响，不能保证任何特定应用联网。

双卡操作必须明确选择作用域。订阅 ID 变化不能当作 SIM 身份；换卡或身份不明时拒绝写入。真实通话、重启、无线配对、不同运营商及可访问性组合仍需独立验收。
